VHS-Sat Lite — Windows
======================

Домашний стриминговый сервер для локальных видеофайлов.
Без установки Python. Просто распакуйте и запустите.

ЧТО УМЕЕТ
---------
* Создавать каналы из папок с видео (mp4, mkv, avi, ts, mov, m4v, webm).
* Крутить их по кругу: random, по дате, по имени.
* Показывать 5-секундный анонс следующего файла перед каждым видео.
* Раздавать канал по HLS (для браузера, телефона, ТВ) и/или multicast UDP
  (для VLC, Kodi, приставок).
* Два порта: админка (8300) и viewer (8301, без пароля, для гостей).

ЧТО НЕ УМЕЕТ
------------
* Спутниковое ТВ (DVB-S/S2), CAM/CI. Для этого нужна полная версия
  из исходников на Linux: https://github.com/andrey-geben/VHS-Sat

БЫСТРЫЙ СТАРТ
-------------
1. Распакуйте архив в удобную папку, например: C:\VHS-Sat-Lite\
2. Запустите VHS-Sat-Lite.exe (двойным кликом).
3. Windows спросит про доступ в сеть для портов 8300 и 8301 → РАЗРЕШИТЬ
   (для «частных сетей», «общедоступные» можно оставить закрытыми).
4. Откроется браузер: http://localhost:8300/setup
5. Создайте администратора (логин + пароль ≥ 6 символов).
6. Меню «Локальные каналы» → создайте первый канал:
   - Название: «Мультики» (или что угодно)
   - Папка: полный путь, например D:\Video\Cartoons
   - Кодек: encode (для первого теста)
   - HLS: включен (для просмотра в браузере)
7. Нажмите «Старт» и откройте viewer в браузере:
   http://<IP-этого-ПК>:8301/

КАК УЗНАТЬ IP ДЛЯ ТЕЛЕВИЗОРА/ТЕЛЕФОНА
-------------------------------------
В PowerShell:  ipconfig
Найдите «IPv4-адрес» вашего Wi-Fi/Ethernet — это и есть <IP-этого-ПК>.
Устройства должны быть в той же Wi-Fi / LAN.

MULTICAST В VLC
---------------
Если в канале включён «Multicast UDP», на любом устройстве в LAN:
VLC → Медиа → Открыть URL → udp://@239.1.1.1:5000 (порт подставьте свой).

ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Рядом с VHS-Sat-Lite.exe автоматически создаются:
  data/       — SQLite база, HLS-сегменты, bumper-клипы
  logs/       — журнал событий (events.jsonl)
  config.yaml — настройки и секретный ключ

При переносе программы копируйте ВСЮ папку целиком, иначе потеряете
каналы и настройки.

ОБНОВЛЕНИЕ
----------
Скачайте новый .zip, распакуйте в новую папку, перенесите туда старые
data\ и config.yaml. Запустите новый .exe.

АНТИВИРУС
---------
Если антивирус ругается на .exe: это сборка PyInstaller, ложное
срабатывание. Добавьте папку в исключения. Публичной цифровой подписи
у файла нет — это нормально для open-source домашних сборок.
