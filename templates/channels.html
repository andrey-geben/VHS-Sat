Подсказки

  • HLS — для браузеров и мобильных в домашней Wi-Fi. Viewer на порту {{ viewer_port }}.
  • Multicast UDP — для VLC/Kodi/приставок. Адрес udp://@239.1.1.1:5000. Работает в локальной сети.
  • Задержка: HLS — 8–15 сек, multicast — 1–2 сек. Для «посмотреть двор в реальном времени» — multicast в VLC.
  • Auto-restart: IPTV и камеры перезапускаются через 3 сек после падения. Папки — нет (падение = ошибка в файлах, надо вмешаться).
  • ⚠ нет сигнала в карточке — HLS-сегмент не обновлялся больше 30 секунд. Поток «залип», проверьте /events.
  • 📋 HLS / 📋 UDP — копируют ссылку для вставки в VLC или на ТВ-приставке.
  • 🔊 Звук: при copy в HLS попадает исходный аудиокодек. Если браузер играет видео без звука — скорее всего, в источнике AC3 / E-AC3 / DTS / G.711. Переключите стратегию на copy_video (видео без изменений, звук → AAC) — это почти бесплатно по CPU.
  • ✎ Изменить — редактирование параметров канала. При сохранении работающий канал перезапускается.
