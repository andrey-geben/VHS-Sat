📡 IPTV из плейлиста провайдера

Вставьте URL M3U/M3U8-плейлиста (или загрузите файл). Сервер распарсит его и покажет список каналов — вы отметите нужные, и они станут отдельными каналами. Дубли по URL автоматически пропускаются.

Провайдер даёт плейлист в личном кабинете. Если плейлист требует авторизации по URL-параметрам — вставьте полный URL, как он выдан.

Подсказки

  • HLS — для браузеров и мобильных устройств в той же Wi-Fi. Открывайте viewer на порту {{ viewer_port }}.
  • Multicast UDP — для VLC/Kodi/приставок. Адрес вида udp://@239.1.1.1:5000. Работает только в пределах локальной сети (IGMP snooping должен быть настроен на свитче, если используется управляемый коммутатор).
  • Задержка: HLS — 8–15 сек, multicast — 1–2 сек. Для «посмотреть двор в реальном времени» включайте multicast и смотрите в VLC.
  • Auto-restart: если IPTV-поток или камера отвалилась, супервизор перезапускает ffmpeg через 3 секунды. Для каналов из папок такого рестарта нет — падение будет видно как OFFLINE и ошибка в /events.
  • Bumper (анонс следующего файла) работает только для каналов из папок — у потоков «следующего файла» нет.
  • Дубли папок и URL блокируются: одна папка = один канал, один URL = один канал.
