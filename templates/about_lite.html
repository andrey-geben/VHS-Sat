Эта редакция

Windows Lite — сборка только для локальных каналов из папок. В ней нет работы с DVB-S/S2, CAM/CI и multicast через dvblast. Для этого нужна полная версия на Linux.

Если нужна спутниковая ретрансляция — разверните полную версию из исходников на Linux. Этот .exe — для дома и локальных папок с видео.

Технологии

  • Flask — веб-интерфейс, REST API, сессии
  • SQLite — каналы, состояние каналов, события
  • ffmpeg — HLS, multicast, bumper-анонсы, запись (позже)
  • hls.js — веб-плеер в viewer для браузеров без нативного HLS
