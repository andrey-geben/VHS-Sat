Ограничения и предупреждения

Только Linux для production-эксплуатации. Windows поддерживается для разработки и тестирования UI/API на stub-бэкенде (демо-данные). Работа с DVB-S/S2, CAM/CI и multicast через dvblast возможна только на Linux — этих утилит и Linux DVB API под Windows не существует.
CI+ не поддерживается. Проект работает с «голым» DVB-CI. Современные CI+ CAM-модули требуют сертифицированного устройства и шифрованного канала «CAM ↔ хост»; без сертификации работа возможна лишь в fallback-режиме (без CI+), если карта и CAM это позволяют.
Юридическое предупреждение. VHS-Sat предназначен для личного / внутреннего использования с легальной подпиской. Ретрансляция платных каналов за пределы частного домохозяйства (в т.ч. через CAM) в РФ и ЕС — лицензируемая деятельность. Ответственность за соблюдение законодательства — на операторе сервера.
