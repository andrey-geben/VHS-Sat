Создать канал

← к списку каналов

Выберите тип источника. Все каналы работают одинаково: HLS для браузера и multicast для VLC/Kodi/приставок.

📁
Из папки
Локальная папка с видеофайлами. Крутятся по кругу с опциональным bumper-анонсом.
📡
IPTV
Один поток от провайдера или импорт целого M3U-плейлиста с выбором нужных каналов.
📹
Видеокамера
RTSP / HLS / HTTP live-поток одиночной камеры. «Двор», «Подъезд», «Дача».
🎥
Мозаика камер
Несколько камер (до 9) на одном экране, как в NVR. Каждая ячейка подписана.

Подсказки

  • HLS — для браузеров и мобильных в домашней Wi-Fi. Viewer на порту {{ viewer_port }}.
  • Multicast UDP — для VLC/Kodi/приставок. Адрес udp://@239.1.1.1:5000.
  • Задержка: HLS — 8–15 сек, multicast — 1–2 сек.
  • ⚠ Лимит IPTV-провайдера. Обычно 1–3 подключения на аккаунт. Больше — тёмный экран.
  • 🔊 Звук: при copy в HLS попадает исходный аудиокодек. Если браузер молчит — copy_video.
  • 🎥 Мозаика — CPU-затратна. 4×1080p → 720p ≈ 15–25% одного ядра i5.
